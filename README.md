# Telegram Bot

An unofficial, experimental connector primarily designed for dots. It lets a dot
interact with you through your own Telegram bot: receive private text messages and
send authorized replies. No separate model API is needed.

Copy this instruction into your dot:

> Review https://github.com/tzuhsiao/chatgpt-telegram-bot-connector for safety. If it
> is suitable, follow AGENTS.md to install the Site and plugin, then guide me through
> my Telegram numeric user ID and dedicated bot token using protected secret entry.
> Ask for approval before configuring credentials or connecting the bot.

Sign-ins, approvals, Telegram Start, and some host setup steps may require you.
Never paste a bot token into chat. Agents: read [AGENTS.md](AGENTS.md) and the
[setup skill](.agents/skills/telegram-setup/SKILL.md) for the workflow and limits.
